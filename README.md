# Primeiros Passos em Machine Learning e Análise de Dados

Repositório destinado aos estudos iniciais e experimentos utilizados por mim na área de Ciência de Dados e Machine Learning. Seu propósito é demonstrar a migração da lógica de programação tradicional para a análise de dados em Python.

# Tecnologias e Bibliotecas Utilizadas

  - Python 3
  - Pandas (Manipulação e Análise de Dados)
  - Kaggle Notebooks (Ambiente de Desenvolvimento)

Neste primeiro laboratório, combinei a teoria dos conceitos fundamentais de Machine Learning (Supervised Learning, Unsupervised Learning e por Reinforcement Learning) com a prática de dois estudos de caso:

1. Feature Engineering e Pré-processamento (Estudo das Mangas):
    * Criação de um DataFrame do zero.
    * Aplicação de lógica condicional para criar novas variáveis de negócio.
    * Tradução de variáveis categóricas para linguagem de máquina (0 e 1).
      
2. Análise Exploratória (Dataset do Titanic):
    * Importação de bases de dados reais no formato CSV.
    * Filtragem condicional complexa de dados.
    * Identificação e extração de insights
    * Limpeza de dados (Data Cleaning): tratamento de valores nulos (NaN) e remoção de colunas inviáveis.
